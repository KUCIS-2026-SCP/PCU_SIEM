# PCU SIEM

Linux 서버의 Apache 및 SSH 인증 로그를 웹 화면에서 조회하고 통계를 확인할 수 있는 간단한 SIEM(Security Information and Event Management) 콘솔입니다.

Flask로 실행되며, 브라우저에서 로그 유형을 선택하고 포함/제외 키워드로 검색할 수 있습니다. 통계와 로그 목록은 기본적으로 5초마다 갱신됩니다.

## 주요 기능

- Apache 접근 로그 조회: `/var/log/apache2/access.log`
- SSH 및 시스템 인증 로그 조회: `/var/log/auth.log`
- Apache 에러 로그 조회: `/var/log/apache2/error.log`
- 공백 또는 쉼표로 구분한 포함 키워드 검색
- 제외 키워드 검색
- Apache HTTP 상태 코드별 통계: `2xx`, `3xx`, `4xx`, `5xx`
- 인증 로그 통계: 로그인 성공, 로그인 실패, `sudo`, 기타 이벤트
- Apache 에러 로그 통계: `notice`, `warn`, `error`, 기타 이벤트
- Chart.js 기반 통계 차트 및 차트 항목 클릭 필터

## 요구 사항

- Linux
- Python 3
- Apache 로그 파일
- 로그 파일을 읽을 수 있는 권한
- Chart.js를 불러올 수 있는 인터넷 연결 (웹 브라우저 기준)

## 설치

Debian/Ubuntu 계열 배포판에서는 다음 명령으로 필요한 패키지를 설치합니다.

```bash
sudo apt update
sudo apt install -y python3 python3-flask
```

## 실행

프로젝트를 홈 디렉터리의 `PCU_SIEM` 폴더에 둔 경우 다음과 같이 실행합니다.

```bash
cd ~/PCU_SIEM
sudo python3 app.py
```

서버가 실행되면 브라우저에서 다음 주소로 접속합니다.

```text
http://<서버 IP 주소>:8080
```

같은 서버의 브라우저에서 확인할 때는 `http://127.0.0.1:8080`을 사용할 수 있습니다.

## 백그라운드 실행

터미널을 종료해도 서버를 유지하려면 다음과 같이 실행합니다.

```bash
sudo nohup python3 app.py > app.log 2>&1 &
```

실행 로그는 `app.log`에서 확인할 수 있습니다.

## 서버 종료

8080 포트를 사용하는 프로세스를 종료합니다.

```bash
sudo fuser -k 8080/tcp
```

프로세스가 정상적으로 실행 중인지 확인하려면 다음 명령을 사용할 수 있습니다.

```bash
ss -ltnp | grep ':8080'
```

## 사용 방법

1. 로그 유형을 선택합니다.
2. 포함할 키워드를 입력합니다. 여러 키워드는 공백 또는 쉼표로 구분합니다.
3. 필요하면 제외할 키워드를 입력합니다.
4. `조회하기`를 눌러 결과를 확인합니다.
5. 통계 차트의 항목을 클릭하면 해당 분류가 검색 조건으로 적용됩니다.

Apache 접근 로그에서 세 자리 숫자 상태 코드를 입력하면 HTTP 상태 코드 기준으로 필터링됩니다. 예를 들어 `400 403 404`를 입력하면 해당 상태 코드의 요청만 조회합니다.

## 보안 주의 사항

- 앱은 `0.0.0.0:8080`에서 동작하므로 네트워크에 연결된 다른 장치에서도 접근할 수 있습니다. 운영 환경에서는 방화벽이나 내부망으로 접근을 제한하세요.
- 앱은 시스템 로그를 읽기 위해 `sudo`로 실행하도록 안내되어 있습니다. 인터넷에 직접 공개하지 마세요.
- 현재 애플리케이션에는 로그인 인증이나 HTTPS가 포함되어 있지 않습니다. 공개 서비스 용도로 사용하기 전에 인증, TLS, 리버스 프록시 등의 보호 계층을 추가해야 합니다.
- 화면에 실행된 Shell 명령이 표시되므로 신뢰할 수 있는 관리자만 접근하도록 구성하세요.
- Apache 또는 SSH가 설치되지 않았거나 로그 경로가 다른 배포판에서는 해당 로그가 표시되지 않을 수 있습니다.
